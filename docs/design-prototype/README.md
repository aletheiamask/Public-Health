# ต้นแบบดีไซน์ "ทะเลตะวันออก" (v2)

ไฟล์ต้นทางของแคนวาสออกแบบหน้าจอ (Artifact แบบ Design) — 11 หน้าจอ:
ประชาชน (หน้าแรกเดสก์ท็อป/มือถือ, ข่าววัคซีน, สมัครงาน), เจ้าหน้าที่ รพ.สต. (งานของฉัน, หนังสือเวียน+รับทราบ, ลาป่วย),
หัวหน้ากลุ่มงาน (กล่องงานรวม + ⌘K, ติดตามรับทราบรายหน่วย, เขียนหนังสือเวียนด่วน) และ Design System

- ไฟล์ `*.dc.html` เป็นรูปแบบ Design Component ของแคนวาส (ต้องเปิดผ่านแคนวาส ไม่ใช่เบราว์เซอร์ตรง ๆ)
- รูปใน `images/` สร้างด้วย AI (Figma generate image) ย่อเป็น WebP — ในไฟล์ .dc.html อ้างอิงเป็น `/_blob/<id>` ของแคนวาส
- ข้อมูลทั้งหมดเป็นข้อมูลจำลอง (ยกเว้นสายด่วน 1422, 1669, 1323)
- ผ่านการทดสอบโดยเอเจนต์ผู้ใช้ 4 ช่วงวัย 2 รอบ (ผู้สูงอายุ, พยาบาล รพ.สต., หัวหน้ากลุ่มงาน, คนรุ่นใหม่)
